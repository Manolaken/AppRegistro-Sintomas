# Registro de Síntomas

Aplicación web instalable para llevar un diario de episodios de dolor abdominal y de lo que los rodea (comidas, medicación, sueño, regla), pensada para enseñárselo al médico.

- Los datos se guardan solo en el dispositivo; no se envían a ningún servidor.
- Funciona sin conexión una vez instalada.
- No diagnostica ni da consejos médicos.

Hecha con React, TypeScript y Vite. Las decisiones del proyecto y su estado están en [`CLAUDE.md`](CLAUDE.md).

## Desarrollo

```
npm install
npm run dev
```
